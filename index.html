ヨット練習を
「見返せる・比較できる・共有できる」記録に

ドライブに溜まる一方の練習・コーチング動画を、AIで自動整理。
「誰が・どの状況で・何を言われたか」を検索・比較・共有できる練習ログに変えます。

既存データは部内共有アカウントでログインしてご覧いただけます。

課題

「撮って終わり」になっている練習動画

コーチが海上で出す指摘も、日々のセッティングも、記録に残らず消えていきます。部内ヒアリングから見えた5つの痛み。

溜まる一方で整理されない

ドライブに大量に蓄積されるが分類されず、価値ある動画も埋もれ、結局見返されない。

反復指摘に気づけない

毎回「同じこと」を言われているのに、本人も指導側も気づけず改善サイクルが回らない。

知見が横展開されない

ある部員への有効なアドバイスが、同じ状況を通る他の部員に共有されない。

速いセッティングを再現できない

リグを日々変えているのに記録が残らず、「あの日速かった設定」を再現できない。

海上の音声が聞き取れない

風・波・エンジンの騒音で、せっかくのコーチの指摘が録音上ほとんど聞き取れない。

ソリューション

動画をアップロードするだけで、練習ログに

AIが自動で「クリーン化 → 文字起こし → 話者分離 → 状況タグ付け → 要約」を行い、選手ごと・状況ごとに検索・比較・共有できる練習ログを生成します。

  1. ①音声クリーン化
    海上ノイズを除去(実装済み)
  2. ②文字起こし
    タイムスタンプ付きで日本語化
  3. ③話者分離
    誰が誰に言ったかを特定
  4. ④状況タグ付け
    風速・波・走り方で分類
  5. ⑤要約・反復指摘検出
    成長を可視化(LLM)

主要機能

課題に一対一で効く3機能

🏷️

状況タグの自動付与

波・風・艇の走り方からタグを割り振り、動画を「検索できる資産」に変える。

🗣️

文字起こし・話者分離・成長管理

誰が誰に何を言ったかを記録・要約し、反復指摘を可視化。他部員の知見も引ける。

🎞️

映像系(フォーム・セールNo.)

真後ろ艇のフォーム抽出、セール番号識別、手ぶれ補正で見返しやすく(後段)。

技術要素

段階連結パイプライン

各段は独立して差し替え可能。実装状況は正直に区別しています。

実装済DeepFilterNet3海上ノイズ除去。実練習動画23本を処理済み・実測リアルタイム約16倍速。
予定faster-whisper large-v3クリーン音声をタイムスタンプ付き日本語テキストへ。
予定pyannote.audio 3.1話者分離で「いつ・誰が」を区間分割。
予定Claude(Anthropic)選手別サマリ・反復指摘検出・状況別の知見抽出。

新規性・競合優位

誰も入れなかった難所「海上音声」を突破

既存のセーリング分析はGPSトラック中心で、口頭コーチングの音声はほぼ扱いません。理由は風・波・エンジン音で屋外の音声系が機能しないため。SailVizはDeepFilterNet3による海上ノイズ除去を実装済みで、この壁を越えています。

サービス主入力口頭コーチング音声
kTool / OutSail / SailViewerGPS・テレメトリ扱わない
SailingMetrics / ChartedSailsGPS・動画同期扱わない
SailViz口頭コーチング＋映像✔ 構造化・検索・比較

消えていくコーチの言葉を、成長の記録に。

指導リソースが限られた学生スポーツの現場から、口頭コーチング活用の新しい標準をつくります。
