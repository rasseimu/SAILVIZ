# プロ動画の勉強ページ(③)設計

①(練習動画の自動紐付け)と②(練習動画への瞬間コメント)の続き。②のコメント表(`video_comments`、`scope='study'`)と表示部品を流用する。

## 目的と理由

Drive の `練習動画/プロ動画` にはプロのセーリング動画があり、勉強のために見ている。GPS データは無いので練習ページでは扱えない。チームで見て、特定の瞬間に「このタックのウェイトの入れ方を見て」のようなコメントを付けて共有したい。

成功の姿: 新しいページで `プロ動画` フォルダの動画一覧から1本選んで再生し、瞬間コメントを付けたり、他のメンバーのコメントをその瞬間に見たり、一覧から飛んだりできる。

## 目標

1. 新しい画面「プロ動画」(既存の画面ごとのアドレスの仕組みで `/study` 等)を作り、ホーム等の既存ナビから行けるようにする。
2. ①で設定した動画ルート(`練習動画`)の中の `プロ動画` フォルダを読み、動画を一覧表示する。サブフォルダがあればフォルダごとにまとめて表示する(深さ2段まで)。※私の判断。
3. 一覧から動画を選ぶと再生する。コメントのある動画には件数を出す。
4. ②と同じ瞬間コメント(付ける・再生中に表示・一覧から飛ぶ・本人編集/削除・管理者削除)。
5. 動画ルートが未設定/権限切れのときは、①と同じ「動画フォルダを設定」「動画フォルダを許可」ボタンを出す。`プロ動画` フォルダが無ければその旨を出す。

## 非目標

- GPS・練習データ・反省との結び付け。
- 動画のアップロード、サーバー保存、他人の PC に無い動画の再生。
- `プロ動画` 以外のフォルダ(`過去のコーチング動画` など)の扱い。将来はフォルダ名を設定で変えられるようにしてもよいが今回はしない。
- 返信・通知・タグ付け。

## アンチゴール

- ②の練習動画のコメントと混ざる。
- 他の組織のメンバーにコメントが見える。
- 動画ルートの権限ダイアログが画面を開いただけで勝手に出る。

## 動画の指し方(決定)

- 組織 + 動画の `name` + ファイルサイズ(バイト)。Drive の同期フォルダでは名前とサイズは各自の PC で一致する。フォルダを移動・改名してもコメントが付いたままになる。
- `video_comments` に `scope='study'`、`practice_day_id=NULL`、`org_id` = 表示中の組織で保存する。

## 権限

- 読む: 表示中の組織のメンバー(ログインアカウント、または自組織の共有ログイン)。
- 書く: ログインアカウントで表示中の組織のメンバー(共有ログインは書けない。②と同じ)。
- 編集: 本人。削除: 本人か組織管理者(②と同じ)。

## API(案)

- `GET /api/study-comments` → 表示中の組織の勉強コメント全件(件数は少ない前提。動画ごとの件数表示にも使う)。各要素は②と同じ形で `videoName`, `videoSize` を持つ。
- `POST /api/study-comments` 本文 `{ videoName, videoSize, positionMs, text }`。
- 編集・削除は②の `PATCH/DELETE /api/video-comments/:cid` を共用(権限判定は scope に応じて組織で行う)。
- ファイル版では 503、画面は「このサーバではコメントを使えません」と出し、再生だけできる。

## 画面

- 左(モバイルでは上)に動画一覧、右(下)に動画プレーヤーとコメント欄。
- コメント欄は②の部品を流用する(同じ見た目・同じ操作)。
- 動画は `URL.createObjectURL` で再生し、別の動画に切り替えたら前の URL を解放する。
- デスクトップ 1280px・モバイル 390px で崩れないこと。

## 制約

- バニラ ESM・ビルドなし。既存の画面切り替え・アドレスの仕組み(`pathFor` / `syncUrl`)に乗せる。
- 新ロジック(フォルダ走査、動画キー、権限)に単体テスト。
- 練習ページ(トラック画面)の動きを変えない。

## builder に任せること

- 画面の置き方(`index.html` 内の新しい view か別 HTML か。既存の作りに合う方)。
- ナビの入口の位置と文言。
- 一覧の並び順(名前順を想定)。

## 追記(2026-10-28)

`練習動画/コーチング(beta)/` に保管されているプロのコーチング動画も、このページで扱う。

- 勉強用フォルダは `プロ動画`・`コーチング(beta)` の2つ(この順で表示。`src/studyfolder.js` の `STUDY_FOLDER_NAMES`)。
- 名前の比較は NFKC + 前後の空白を除く + 小文字(`コーチング（beta）`・`コーチング(Beta)` も同じとみなす)。表示は実際のフォルダ名。
- 一覧はフォルダを開いて進む形。最上段は動画ルート(`練習動画`)で、その子が見つかった勉強用フォルダ。最上段に動画は出さない(ルート直下の動画・`2026練習` などは扱わない)。各勉強用フォルダの下4段まで読み、動画の無いフォルダは出さない。
- 動画ルート自体が勉強用フォルダのどれかなら、そのフォルダを最上段にする(直下の動画も出す)。
- パンくずは `練習動画 › プロ動画 › A大会` の形で、最上段も押せる(今いる段は押せない)。
- どちらのフォルダも無ければ「プロ動画・コーチング(beta) フォルダが見つかりません」と出す。
- コメントの付け方(動画の 名前 + サイズ)と API は変えない。フォルダの場所はキーに含めないので、既存のコメントはそのまま付く。
- ページ名・ナビの「プロ動画」はそのまま。
- 既知の制限: 正規化で同じ名前になるフォルダ(NFC で同じ名前、例: 濁点の形だけが違う `プロ動画` が2つ)が同じ段に並ぶと、パスが同じになるため片方に入れないことがある。
- 既知の制限: 同じファイル(名前 + サイズが同じ)を複数のフォルダに置くと、コメントは共有される(フォルダの場所をキーに含めないための意図どおりの動き)。
