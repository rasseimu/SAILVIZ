# sailviz-field (Flutter 現場アプリ #56) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** スマホでGPSをバックグラウンド記録し、着岸後に1タップで sailviz バックエンドへ半自動アップロードし、反省入力・ロードマップ編集・目標/課題の簡易表示を行う Flutter 現場アプリ v1 を、新規リポジトリに実装する。

**Architecture:** 純ロジック（CSV生成/正規化/プリフィル/アメダス/roadmapマージ）を UI・HTTP・プラットフォームAPIから分離し `flutter test` で TDD。HTTP は `ApiClient` インターフェース越しに叩き、テストは `FakeApiClient` を注入して契約テスト。GPS は前景サービス(`flutter_foreground_task`)内の `geolocator` ストリームを購読し点を即 SQLite に追記、停止後に `buildSensorCsv` で CSV 化して `/api/sensor-imports`→`/commit` の2段で送る。

**Tech Stack:** Flutter / Riverpod / dio / cookie_jar / flutter_secure_storage / shared_preferences / geolocator / flutter_foreground_task / sqflite（テストは sqflite_common_ffi）。

**Spec:** `docs/superpowers/specs/2026-10-03-field-app-design.md`（本プランはこの設計書を実装する。実装は新規リポジトリ `sailviz-field` で行い、本プランと spec を両方参照する）。

## Global Constraints

- **バックエンド無改修**。既存エンドポイントのみ使用（任意改修は Authorization ヘッダ1行のみ、v1では使わない）。
- ベースURL は環境変数（`--dart-define=SAILVIZ_BASE_URL=...`）。既定 `https://sailviz-sit.fly.dev`、ローカル `http://localhost:8000`。
- **反省ファイル名規則**: `^[A-Za-z0-9._-]+\.sailviz\.json$`（日本語不可）。反省ファイルは `sailviz-<YYYYMMDD-HHmm>-<slug>.sailviz.json`。slug は member id `m0..m19`。
- **反省スキーマは sailviz と完全一致**。rig は `RIG_FIELDS` 全12キー（空欄→null、0は保持）、notes は `NOTE_FIELDS` 全5キー（未入力→""）。`people[0]` = 自分フルネーム。
- **GPS CSV 列名は小文字一致**: `time, latitude, longitude, speed, horizontalaccuracy`（必須=time/latitude/longitude、列順任意）。time は ISO8601（timezone付き）。speed は m/s、horizontalaccuracy は m。
- **アメダス**: point=`46141`（辻堂）。URL は `https://www.jma.go.jp/bosai/amedas/data/point/{point}/{yyyyMMdd}_{HH}.json`（HH=3時間ブロック開始・JST）。
- **部員名簿 20名**を同梱。`fullName="<family> <given>"`（半角スペース区切り）、id=`m<index>`。
- **バックグラウンドGPS記録必須**（iOS+Android・想定連続10時間）。点は即 SQLite へ（メモリに溜めない）。
- すべての書込(PUT/POST)は unlock(cookie) 必須。401 は unlock 画面へ誘導。
- 失敗は握ってローカル永続・手入力・キュー滞留にフォールバック（操作を止めない）。
- TDD。各タスクは失敗するテスト→最小実装→テスト通過→コミットのサイクル。純ロジックは `flutter test`、recorder/UI/権限/実機バックグラウンドは手動確認。

## Review Focus

- **GPS の speed/accuracy が無い端末（null）**: `buildSensorCsv` は `"null"` 文字列ではなく**空セル**を出すこと。必須列欠損行はそもそも出さない。→ Task 7 のテストで固定。
- **アップロード時に同日の自分の反省プロジェクトが無い**: commit 先が無く 404 になるので、**先に軽量プロジェクトを PUT 作成**してから commit すること。→ Task 12 のテストで固定。
- **ロードマップ PUT が他部員キーを消す**: `mergeMyRoadmapKey` は自分キー以外を不変で保持すること。→ Task 5 のテストで固定。
- **Position.timestamp の時刻がサーバ `parseTime` で解釈できない**: timezone 付き ISO8601 で出し、UTC/JST いずれでも正しい epoch になること。→ Task 7 のテストで固定。
- **記録中にクラッシュ/電池切れ→再起動**: `status='recording'` のまま残ったセッションを検出して復元（確定/破棄）できること。→ Task 14 のテストで固定。

// lib/data/schema.dart
const List<String> rigFields = [
  'boatNo', 'gear', 'prebend', 'rake', 'sideTension', 'foreTension',
  'puller', 'peakRope', 'bridleHeight', 'jibLeader', 'jibPull', 'vangPull',
];
const List<String> noteFields = ['goal', 'issue', 'discovery', 'slowFactor', 'fastFactor'];

num? toNum(Object? v) {
  if (v == null || v == '') return null;
  if (v is num) return v;
  return num.tryParse(v.toString());
}

Map<String, num?> normalizeRig(Map? rig) {
  final out = <String, num?>{};
  for (final f in rigFields) out[f] = toNum(rig?[f]);
  return out;
}

Map<String, String> normalizeNotes(Map? notes) {
  final out = <String, String>{};
  for (final f in noteFields) out[f] = (notes?[f] ?? '').toString();
  return out;
}

Map<String, num?> previousRig(List<Map> list) {
  final last = list.isNotEmpty ? list.last : null;
  return normalizeRig(last?['rig'] as Map?);
}

Map<String, dynamic> createReflection({
  required String id,
  required int createdAt,
  String text = '',
  List<String> people = const [],
  List videos = const [],
  Map? wind,
  Map? practice,
  Map? rig,
  Object? waveHeight,
  Map? notes,
}) {
  return {
    'id': id,
    'createdAt': createdAt,
    'text': text,
    'people': [...people],
    'videos': [for (final v in videos) {'name': v['name'], 'tMs': v['tMs'] ?? 0}],
    'wind': wind == null ? null : {...wind},
    'practice': practice == null ? null : {...practice},
    'rig': normalizeRig(rig),
    'waveHeight': toNum(waveHeight),
    'notes': normalizeNotes(notes),
  };
}
```

// lib/data/project.dart
const _jstOffsetMs = 9 * 60 * 60 * 1000;

String _two(int n) => n.toString().padLeft(2, '0');

// epoch ms を JST の DateTime(UTC表現) に。
DateTime _jst(int ms) => DateTime.fromMillisecondsSinceEpoch(ms + _jstOffsetMs, isUtc: true);

String _stampYmdHm(int ms) {
  final d = _jst(ms);
  return '${d.year}${_two(d.month)}${_two(d.day)}-${_two(d.hour)}${_two(d.minute)}';
}

String reflectionFileName({required int startedMs, required String slug}) =>
    'sailviz-${_stampYmdHm(startedMs)}-$slug.sailviz.json';

String projectFileNameForGps({required int practiceMs, required String slug}) =>
    'sailviz-${_stampYmdHm(practiceMs)}-$slug-gps.sailviz.json';

Map<String, dynamic> buildReflectionProject({
  required Map reflection,
  required int savedAt,
  required int practiceDate,
}) {
  return {
    'version': 1,
    'savedAt': savedAt,
    'reflections': [reflection],
    'practiceDate': practiceDate,
  };
}

// lib/data/roadmap.dart
Map<String, dynamic> mergeMyRoadmapKey(Map overlay, String fullName, Map entry) {
  final out = <String, dynamic>{};
  overlay.forEach((k, v) => out[k.toString()] = v);
  out[fullName] = entry;
  return out;
}

int roadmapProgress(List milestones) {
  for (var i = 0; i < milestones.length; i++) {
    if ((milestones[i] as Map)['done'] != true) return i;
  }
  return milestones.length;
}

// lib/data/wind.dart
const amedasPoint = '46141';
const amedasName = '辻堂';
const _jstOffsetMs = 9 * 60 * 60 * 1000;

const _dirNames = [
  '静穏', '北北東', '北東', '東北東', '東', '東南東', '南東', '南南東',
  '南', '南南西', '南西', '西南西', '西', '西北西', '北西', '北北西', '北',
];

String windDirName(int? idx) =>
    (idx != null && idx >= 0 && idx <= 16) ? _dirNames[idx] : '不明';

String _two(int n) => n.toString().padLeft(2, '0');
DateTime _jst(int ms) => DateTime.fromMillisecondsSinceEpoch(ms + _jstOffsetMs, isUtc: true);

String blockHour(int hour) => _two((hour ~/ 3) * 3);

String amedasUrl(int ms, {String point = amedasPoint}) {
  final d = _jst(ms);
  final ymd = '${d.year}${_two(d.month)}${_two(d.day)}';
  return 'https://www.jma.go.jp/bosai/amedas/data/point/$point/${ymd}_${blockHour(d.hour)}.json';
}

// 'yyyyMMddHHmmss'(JST) → epoch ms
int? _keyToMs(String key) {
  if (key.length < 14) return null;
  final iso = '${key.substring(0, 4)}-${key.substring(4, 6)}-${key.substring(6, 8)}'
      'T${key.substring(8, 10)}:${key.substring(10, 12)}:${key.substring(12, 14)}+09:00';
  return DateTime.tryParse(iso)?.millisecondsSinceEpoch;
}

Map<String, dynamic>? parseWind(Map? json, int targetMs) {
  if (json == null) return null;
  int? bestDiff;
  double? speed;
  int? dirIdx;
  int? obsMs;
  json.forEach((key, entry) {
    if (entry is! Map) return;
    final s = entry['wind'] is List ? (entry['wind'] as List).first : null;
    final d = entry['windDirection'] is List ? (entry['windDirection'] as List).first : null;
    if (s is! num || d is! num) return;
    final ms = _keyToMs(key.toString());
    if (ms == null) return;
    final diff = (ms - targetMs).abs();
    if (bestDiff == null || diff < bestDiff!) {
      bestDiff = diff;
      speed = s.toDouble();
      dirIdx = d.toInt();
      obsMs = ms;
    }
  });
  if (bestDiff == null) return null;
  return {'speed': speed, 'dirIdx': dirIdx, 'dirName': windDirName(dirIdx), 'obsMs': obsMs};
}

class DioApiClient implements ApiClient {
  final Dio _dio;
  DioApiClient(String baseUrl, CookieJar jar)
      : _dio = Dio(BaseOptions(baseUrl: baseUrl, validateStatus: (s) => s != null && s < 500)) {
    _dio.interceptors.add(CookieManager(jar));
  }

  Never _check(Response r) => throw ApiException(r.statusCode ?? 0, r.data?.toString() ?? '');

  @override
  Future<bool> unlock(String password) async {
    final r = await _dio.post('/api/unlock', data: {'password': password});
    return r.statusCode == 200;
  }
  @override
  Future<bool> authOk() async {
    final r = await _dio.get('/api/auth');
    return r.statusCode == 200 && (r.data['unlocked'] == true);
  }
  @override
  Future<List<Map>> summaries() async {
    final r = await _dio.get('/api/summaries');
    if (r.statusCode != 200) _check(r);
    return (r.data as List).cast<Map>();
  }
  @override
  Future<Map> getProject(String name) async {
    final r = await _dio.get('/api/projects/$name');
    if (r.statusCode != 200) _check(r);
    return r.data as Map;
  }
  @override
  Future<void> putProject(String name, Map project) async {
    final r = await _dio.put('/api/projects/$name', data: project);
    if (r.statusCode != 200) _check(r);
  }
  @override
  Future<Map> getRoadmap() async {
    final r = await _dio.get('/api/overlays/roadmap');
    if (r.statusCode != 200) _check(r);
    return r.data as Map;

    if (r.statusCode != 200) _check(r);
  }

    final r = await _dio.post('/api/sensor-imports', data: {'person': person, 'csv': csv});
    if (r.statusCode != 200) _check(r);
    return r.data as Map;

// lib/db/sync_queue.dart
import 'dart:convert';
import 'package:sqflite/sqflite.dart';

class SyncQueue {
  final Database db;
  SyncQueue(this.db);

  Future<int> enqueue({required String kind, required String dedupeKey, required Map payload}) async {
    final existing = await db.query('sync_jobs',
        where: 'dedupeKey = ?', whereArgs: [dedupeKey], limit: 1);
    if (existing.isNotEmpty) return existing.first['id'] as int;
    return db.insert('sync_jobs', {
      'kind': kind, 'dedupeKey': dedupeKey, 'payload': jsonEncode(payload), 'status': 'pending',
    });
  }

  Future<List<Map>> pending() async =>
      db.query('sync_jobs', where: "status = 'pending'", orderBy: 'id');

  Future<void> markSynced(int id) async =>
      db.update('sync_jobs', {'status': 'synced'}, where: 'id = ?', whereArgs: [id]);

  Future<void> markFailed(int id) async => db.rawUpdate(
      "UPDATE sync_jobs SET status='failed', tries=tries+1 WHERE id=?", [id]);
}

// lib/gps/recorder.dart
import 'dart:async';
import 'package:geolocator/geolocator.dart';
import 'package:flutter_foreground_task/flutter_foreground_task.dart';
import '../data/sensor_csv.dart';
import '../db/gps_store.dart';

class Recorder {
  final GpsStore store;
  StreamSubscription<Position>? _sub;
  final _count = StreamController<int>.broadcast();
  int _n = 0;
  Recorder(this.store);

  Stream<int> get pointCount => _count.stream;

  Future<bool> ensurePermissions() async {
    var p = await Geolocator.checkPermission();
    if (p == LocationPermission.denied) p = await Geolocator.requestPermission();
    if (p == LocationPermission.deniedForever || p == LocationPermission.denied) return false;
    // Always(背面)権限はプラットフォームの設定誘導。通知権限は foreground_task が要求。
    return true;
  }

  LocationSettings _settings() {
    // 1Hz 目安・高精度。distanceFilter:0 で時間駆動。
    return const LocationSettings(accuracy: LocationAccuracy.high, distanceFilter: 0);
  }

  Future<String> start() async {
    final id = 'sess_${DateTime.now().millisecondsSinceEpoch}';
    await store.startSession(id, DateTime.now().millisecondsSinceEpoch);
    await FlutterForegroundTask.startService(
      notificationTitle: 'GPS記録中 ●',
      notificationText: '練習の軌跡を記録しています',
    );
    _n = 0;
    _sub = Geolocator.getPositionStream(locationSettings: _settings()).listen((pos) async {
      await store.addPoint(id, GpsPoint(
        t: pos.timestamp.millisecondsSinceEpoch,
        lat: pos.latitude, lon: pos.longitude,
        speed: pos.speed, accuracy: pos.accuracy,
      ));
      _count.add(++_n);
    });
    return id;
  }

  Future<void> stop(String sessionId) async {
    await _sub?.cancel();
    _sub = null;
    await store.stopSession(sessionId, DateTime.now().millisecondsSinceEpoch);
    await FlutterForegroundTask.stopService();
  }
}

// lib/providers/identity.dart
import 'package:shared_preferences/shared_preferences.dart';
import '../data/members.dart';
import '../net/api_client.dart';

class Identity {
  final Member? me;
  final bool unlocked;
  const Identity({this.me, this.unlocked = false});
  Identity copyWith({Member? me, bool? unlocked}) =>
      Identity(me: me ?? this.me, unlocked: unlocked ?? this.unlocked);
}

class IdentityController {
  final ApiClient api;
  final SharedPreferences prefs;
  Identity state = const Identity();
  IdentityController(this.api, this.prefs);

  Future<void> load() async {
    final id = prefs.getString('memberId');
    if (id != null) {
      final m = memberList().where((e) => e.id == id);
      if (m.isNotEmpty) state = state.copyWith(me: m.first);
    }
    state = state.copyWith(unlocked: await api.authOk());
  }

  Future<void> selectMember(Member m) async {
    await prefs.setString('memberId', m.id);
    state = state.copyWith(me: m);
  }

  Future<bool> unlock(String password) async {
    final ok = await api.unlock(password);
    state = state.copyWith(unlocked: ok);
    return ok;
  }
}

  required Map roadmapOverlay,
}) {
  // 自分の反省を持つサマリを practiceDate 降順で。
  final mine = <Map>[];
  for (final s in summaries) {
    final refls = (s is Map ? s['reflections'] : null) as List? ?? [];
    for (final r in refls) {
      if (r is Map && (r['people'] as List?)?.contains(fullName) == true) {
        mine.add({'practiceDate': s['practiceDate'] ?? 0, 'refl': r});
      }
    }
  }
  mine.sort((a, b) => (b['practiceDate'] as num).compareTo(a['practiceDate'] as num));
  final latest = mine.isNotEmpty ? (mine.first['refl'] as Map) : null;
  final notes = (latest?['notes'] as Map?) ?? {};

  final entry = (roadmapOverlay[fullName] as Map?) ?? {};
  final milestones = (entry['milestones'] as List?) ?? [];

  return {
    'lastIssue': (notes['issue'] ?? '').toString(),
    'lastDiscovery': (notes['discovery'] ?? '').toString(),
    'currentGoal': (entry['goal'] ?? '').toString(),
    'progressIndex': roadmapProgress(milestones),
    'progressTotal': milestones.length,
  };
}
```
