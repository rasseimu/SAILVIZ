## 背景

現在のホーム画面では、トラック数・反省数・動画数・風情報しか表示されない。

GPSを読み込んだ直後に分析結果を表示し、
初回利用でもSailVizの価値を感じられるようにする。

## ユーザーストーリー

選手として、GPSをアップロードした直後に今日の練習内容を把握したい。
なぜなら、複雑な画面操作をせずに振り返りを始めたいから。

## 表示内容

### 練習全体

- 練習開始・終了時刻
- 練習時間
- GPSが取得できた艇数
- GPSデータの品質
- 推定風軸
- 推定風軸の変動幅

### 艇ごと

- 走行距離
- 記録時間
- 平均速度
- 最高速度
- タック回数
- ジャイブ回数

### 複数艇がある場合

- 比較可能だった時間
- クローズVMGが最も高かった艇
- ランニングVMGが最も高かった艇

## UI

GPS読込完了後、サイドパネルまたはモーダルで自動表示する。

以下の導線を付ける。

- 「軌跡を見る」
- 「艇ごとに比較する」
- 「今日の反省を書く」

同じ練習で2回目以降に開いた場合は、自動表示せずホームカードから開けるようにする。

## 注意事項

風向は実測値ではなくGPS軌跡からの推定値なので、
画面上では「推定風軸」と表記する。

推定できない場合は、無理に数値を出さず理由を表示する。

例：

- タック数が不足しています
- GPS精度が不足しています
- 比較可能な区間がありません

## 受け入れ条件

- [ ] GPSが1艇でもサマリを表示できる
- [ ] GPS読込完了後、3秒以内に表示される
- [ ] 2艇以上の場合のみ艇間比較を表示する
- [ ] 推定値には「推定」と表示される
- [ ] 算出不能時に `0` ではなく理由を表示する
- [ ] 保存後に同じサマリを再表示できる
- [ ] サマリ計算ロジックに単体テストがある

## 対象外

- AIによる助言
- 動画の分析
- 過去練習との比較
- セッティングの良し悪しの判定
